**Project name** - Internship Tracker

Purpose:

An application to help students/applicants keep track of
all internships they have applied for.

Problem:

Internship applications can become difficult to track when
there are many companies, application dates, interview rounds,
and different application statuses.

Solution:

Internship Manager will provide a single place to add,
view, edit, delete, search and track internship applications.
